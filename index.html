Calculation Rules

Explicit assumptions used by the planner.

UnitsCPU input is always millicores. Memory input is always MiB. Example: 500 = 500m = 0.5 core; 6144 = 6144 Mi.
Istio KPIIstio Cores = sum of the Istio sidecar CPU column. Replicas are deliberately NOT applied to this KPI.
SchedulingApplication CPU = CPU Request × replicas. Scheduling CPU = (CPU Request + Istio CPU) × replicas. Memory follows the same model.
Nodes8/32, 16/64 or 32/128 CPU/GiB nodes. 80% usable. Node count is the larger of CPU- and memory-driven counts.
